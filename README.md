# ai

실시간 MAVLink 텔레메트리에 대한 정상 패턴 기반 이상탐지 파트입니다. 서로 다른 모델 2종을 하나의 레포에서 공통 기준으로 비교합니다.

## 디렉터리

| 경로 | 역할 |
| --- | --- |
| `src/preprocessing/` | 시간 정렬, 입력 특징, 윈도우, 정규화 |
| `src/models/model_1/` | 모델 1 |
| `src/models/model_2/` | 모델 2 |
| `src/evaluation/` | 공통 지표, 임계값, 모델 비교 |
| `src/inference/` | 실시간 추론과 UI 결과 전달 |
| `configs/` | 비밀정보를 제외한 실험 설정 |
| `notebooks/` | 탐색·분석 노트북 |
| `tests/` | 전처리·모델 인터페이스 검증 |

## 개발 기준

- 주 입력은 PX4 MAVLink 텔레메트리이며, ULog는 보조 검증 자료입니다.
- 두 모델은 공통 입력 계약, 전처리, 데이터 분할과 평가 기준을 사용합니다.
- 비행/실험 단위로 Training·Validation·Test를 나누어 인접 윈도우 누출을 방지합니다.
- 정규화 통계량은 Training에서만 구하고, 임계값은 Validation을 기준으로 정합니다.
- 이상 주입 플래그와 숨겨진 열화 설정은 모델 입력에서 제외합니다.
- 결과에는 정상/이상 판단, 시간/구간, 대상 부품을 명시합니다. 대상 식별 방법은 별도로 구현·검증합니다.
- 데이터셋, 기업 로그, 학습 가중치는 Git에 넣지 않습니다. 저장 위치와 데이터 버전은 별도로 관리합니다.

## 시작 상태

모델과 프레임워크는 아직 선정하지 않았습니다. 현재는 협업용 폴더와 문서만 있으며 학습·추론·성능 검증은 구현 이후 진행합니다. 모델 1·2 구현을 위해 별도 레포를 만들지 않고, 공통 코드와 각 모델 디렉터리를 사용합니다.
